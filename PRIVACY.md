# プライバシーポリシー / Privacy Policy

最終更新日 / Last updated: 2026-11-03

## 日本語

Show Password on Hover（以下「本拡張機能」）は、いかなるユーザーデータも収集・送信・保存しません。

- 本拡張機能が行うのは、マウスが乗ったパスワード入力欄の表示形式（`type` 属性）を一時的に切り替えることだけです。
- 入力内容やページの内容を読み取ったり、記録したりしません。
- 外部のサーバーとの通信は一切行いません。
- Cookie やブラウザのストレージは使用しません。
- 第三者にデータを提供することはありません。

ご質問は GitHub の Issues からお寄せください：https://github.com/jojonki/show-password/issues

## English

Show Password on Hover ("the extension") does not collect, transmit, or store any user data.

- All the extension does is switch the display mode (the `type` attribute) of the password field under the mouse for a moment.
- It does not read or record what you type or the content of any page.
- It makes no network requests to any server.
- It does not use cookies or browser storage.
- It does not share any data with third parties.

If you have questions, please open an issue on GitHub: https://github.com/jojonki/show-password/issues
